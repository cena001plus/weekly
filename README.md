# 🚀 Weekly 产品与设计周刊

> 每周精选优质独立产品、开源工具与设计灵感。连接创造者，发现好作品。

欢迎独立创客、开源作者与设计师在此自荐你的作品，让更多人看到你的创意。

---

## 📌 如何自荐你的作品？

1. **GitHub 自荐（推荐）**：直接点击 👉 **[新建自荐 Issue](https://github.com/cena001plus/weekly/issues/new?template=submit.yml)** 提交你的作品。
2. **官网直接上架**：访问我们的官方展台 👉 **[你的网站名称与域名](https://www.builderoom.com)**，提交后经审核可直接全站展示。

> 💡 **入选规则**：每周我们会从自荐池与官网已发布的作品中挑选精选项目，汇总为周刊归档，并同步至全网多渠道曝光。
